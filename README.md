# GlobeKit

GlobeKit 是一个基于 libxposed Modern API 的应用级地区环境模块。它只在 LSPosed 作用域内工作，为应用提供一致的 SIM、运营商、语言、时区和位置参数。

## 功能

- 通过“地区 + 运营商”生成完整环境配置
- 覆盖 SIM/网络国家码、运营商名称和 MCC-MNC
- 覆盖应用进程读取到的语言、IANA 时区、实时 UTC 偏移和 GPS 坐标
- 内置 32 个常用地区及对应运营商
- 使用 Remote Preferences 保存配置
- 保留默认配置，并支持为 LSPosed 作用域内每个应用单独设置完整覆盖
- 语言可跟随所选地区、跟随系统语言或独立选择，例如日本地区搭配简体中文
- 地区与语言列表支持搜索名称和代码，可快速定位城市、地区及语言
- 配置对象显示应用图标、名称和包名，并支持搜索应用名称及包名
- 可分别清除默认配置和应用覆盖，按配置优先级回退
- 作用域完全由 LSPosed 管理器控制
- 首页三点菜单提供设置、手动检查更新和关于
- 设置支持浅色、深色、跟随系统、五种主题颜色及隐藏桌面图标
- 主题颜色提供色块预览，支持启动时自动检查更新和新版提示

## 兼容性

- 适用于 Android 11 及以上系统，需搭配支持 libxposed Modern API 101 及以上的 LSPosed

## 安装与使用

1. 从项目 Releases 下载已签名 APK 并安装。
2. 在 LSPosed 中启用 GlobeKit，并勾选需要生效的应用。
3. 打开 GlobeKit，在“配置对象”中选择“默认配置”或作用域内的应用包名。
4. 选择地区、运营商和语言后保存。语言可以“跟随所选地区”“跟随系统语言”，也可以独立选择。
5. 强制停止并重新打开目标应用，使配置生效。

配置页会显示当前作用域应用数量和所选对象的配置状态。切换配置对象前请保存修改；从 LSPosed 返回配置页时会重新读取作用域与已保存的配置。

生效优先级为“应用独立配置 → 默认配置 → 真实系统环境”。应用独立配置包含完整的地区、运营商与语言选项，不随默认配置变化。点击“清除应用覆盖，跟随默认配置”仅清除当前应用的配置；在默认配置下点击“恢复系统默认”仅清除默认配置，保留其他应用的独立配置。旧版本保存的配置会自动继续作为默认配置使用，语言默认跟随地区。

应用列表由 LSPosed 作用域提供，以包名显示，无需读取全部已安装应用。配置按包名区分，同一应用的不同进程及不同用户下的相同包名共享配置。

保存和清除配置后都需要重启目标应用。目标应用可能缓存已经读取的地区数据；遇到未立即变化的情况，请先彻底结束其进程后再测试。

选择“跟随系统语言”时，模块不覆盖语言相关接口，保留目标应用原本读取到的语言、语言列表和资源配置；如果系统为目标应用单独设置了语言，该设置也会保留。地区、运营商、时区和坐标仍按所选配置覆盖。

## 设置与更新

首页右上角三点菜单可打开设置、检查更新及关于。设置提供浅色、深色和跟随系统，以及靛蓝、蓝色、绿色、橙色、玫红五种界面主题色；不改变图标配色。主题选项只影响配置界面，不改变作用域应用的地区配置。

隐藏桌面图标前会弹出确认。隐藏后仍可从“系统设置 → 应用 → GlobeKit → 打开”或 LSPosed 模块页打开，在设置中关闭开关即可恢复图标。

默认每次打开应用时静默检查一次本仓库 GitHub Releases 的最新正式版，可在设置中关闭；应用内切换页面或更换主题不重复检查。发现新版后主页显示可点击的更新提示，关于页及设置中的当前版本显示红点；点击当前版本可随时手动检查。关闭自动检查后，主页也隐藏更新提示。自动检查失败不弹窗，保留已知的更新信息；手动检查会明确显示结果。应用关闭后不定时唤醒检查，不会自动下载安装 APK。

## 作用范围

GlobeKit 修改的是目标应用通过 Android Java 框架读取到的环境信息。IP 地址、账号注册地区、服务端记录、设备硬件标识，以及应用通过原生代码或自有网络接口收集的信息不在覆盖范围内。不同应用的地区判定策略不同，因此不承诺对所有应用产生相同结果。

## 隐私

GlobeKit 不申请运行时权限。自动或手动检查更新时访问 GitHub，不收集或上传环境配置。用户选择的地区与运营商保存在 LSPosed 的 Remote Preferences 中。完整说明见 [PRIVACY.md](PRIVACY.md)。

## 构建

要求：JDK 21、Android SDK 37。项目使用 Gradle Wrapper 和固定版本的 libxposed 依赖。

Debug 构建：

```powershell
.\gradlew.bat :app:assembleDebug
```

产物位于 `app/build/outputs/apk/debug/GlobeKit-<版本号>-debug.apk`。

Release 构建：

```powershell
.\gradlew.bat :app:assembleRelease
```

产物位于 `app/build/outputs/apk/release/GlobeKit-<版本号>-release.apk`。
